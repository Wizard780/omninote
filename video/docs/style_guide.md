# Style guide

No reference supplied. Named style: **the product's own language** — a quiet ink window, lowercase mono,
the keyword-snap as the signature move.

- Ground: Knight background #0E0F13 (the frame ground *is* the theme; it changes with the theme wipe).
- Type: #E6E6E6 main, #9CA3AF results, #6B6F7B comments/status, accent #7C8CF8 (Knight accent1). Link/checkbox
  blue #5A9AF8 (sampled from screenshot-list.png). Dracula and Paper colors appear only in the theme beat.
- Faces: SF Mono (the app's default editor font) is both UI and display face. SF Pro only for the status bar
  (the app uses monospacedDigitSystemFont there).
- Window: drawn from values sampled off the real screenshots: radius ~38px@2x, 1px top rim #3E3F42, traffic lights
  r13 at (32,32)/(78,32)/(124,32) #EC6765 #F2CA44 #65C466, scrollbar track x732–753 #191A1E, text x=38, first
  baseline 120, line height 34, status baseline H-18.
- Motion: text enters by typing, leaves by backspace or select+delete (editor verbs, never fades). Springs:
  micro for keys/markers, panel for window/camera, heavy for the hero word. No playful.
- Shots: one continuous window that never cuts; a header word to its side mirrors the current keyword.
- Transitions: two-finger swipe (finger-tracked drag then spring commit), circular theme wipe from the gear corner,
  caret→window and window→icon morphs.
