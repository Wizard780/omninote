- Product facts (fixed): keywords math / list / sum / avg / count / timer / code; results appear after `=`;
  `/x` toggles list items; two-finger swipe through the stack; Antinote themes load unchanged; ⌥A shows or
  hides from any app; free, open source (MIT), macOS 14+, github.com/Wizard780/omninote.
